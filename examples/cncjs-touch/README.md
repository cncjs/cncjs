# CNCjs Touch — experimental touchscreen interface

I (@storm8488) have been working on this CNCjs touchscreen prototype, with AI coding assistance. I am sharing it so that someone who already owns a working CNC can help review, test and finish it. I currently do not have an operational CNC available for physical validation. This is unfinished work, not a production-ready machine interface.

The source package, offline tests and English handoff documentation are being added on this draft contribution branch.
