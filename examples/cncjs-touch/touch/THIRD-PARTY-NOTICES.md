# Shopfloor Tablet reference

CNCjs Touch's coordinate-entry workflow and incremental tool-position overlay are inspired by cncjs/cncjs-shopfloor-tablet at commit a44560bce2191dd087c2436b48a0d348ac7f34cc:
https://github.com/cncjs/cncjs-shopfloor-tablet

The integration uses new code fitted to CNCjs Touch's simulation, state checks and cached PNG previews. It does not embed Shopfloor's application, libraries, automatic reconnection or command transport. The upstream notice is retained for these adapted concepts and any substantial derivation.
