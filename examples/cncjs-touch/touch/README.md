# CNCjs Touch browser assets

For a disconnected local demonstration, run `node preview-server.cjs` from the
parent directory and open the localhost URL it prints. Review the integration
notes in [../README.md](../README.md) before connecting to a real CNCjs server.

`simulation.html` provides the virtual interface. `index.html` is the real-interface
entry point. French, English and Spanish are available in Settings, including
operator guidance and journal exports. Hardware validation and completion of
real movement, origin and probing remain outstanding; see [../HANDOFF.md](../HANDOFF.md).
