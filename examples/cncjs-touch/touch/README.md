# CNCjs Touch browser assets

For a disconnected local demonstration, run `node preview-server.cjs` from the parent directory and open the localhost URL it prints. Do not open `index.html` against a live CNCjs installation without reviewing the integration notes in [../README.md](../README.md).

`simulation.html` provides the virtual interface. `index.html` is the real-interface entry point. The interface currently uses French labels; English localization remains part of the handoff work.
